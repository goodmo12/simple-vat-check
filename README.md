# 간이과세 될까?

내 업종과 사업장이 **간이과세 배제 대상인지** 국세청 고시 원문과 대조해 확인하는 정적 웹도구입니다.

👉 **https://goodmo12.github.io/simple-vat-check/**

---

## 이 도구는 무엇인가

간이과세 배제기준은 국세청이 매년 고시하는데, 원문이 한글(HWPX) 문서라 자기 조건에 해당하는지 확인하려면 수십 페이지를 뒤져야 합니다. 이 도구는 그 대조 작업을 대신합니다.

- **종목기준** — 업종 키워드나 6자리 업종코드로 배제업종 127건과 대조하고, 고시 제4조의 지역 조건(서울특별시·광역시 / 수도권 17개 시)을 함께 확인합니다.
- **지역기준** — 건물명·지명으로 검색하거나 지방국세청 → 세무서로 좁혀 들어가, 해당 행의 **적용범위 원문을 그대로** 보여줍니다.

## ⚠️ 확정 판정 도구가 아닙니다

**이 도구의 결과는 참고용이며, 최종 판단은 반드시 관할 세무서나 세무대리인의 확인을 받으십시오.**

그럴 수밖에 없는 이유가 고시 자체에 있습니다.

- **고시 제7조** — 관할세무서장의 확인을 거쳐 예외가 인정될 수 있습니다. 즉 고시 문언만으로는 어떤 도구도 100% 확정할 수 없습니다.
- **고시 제6조(적용순위)** — 문언대로 읽으면 지역기준이 무력화되는 해석이 나오는데, 이 해석이 확정되어 있지 않습니다. 그래서 이 도구는 **종목기준과 지역기준 결과를 하나의 결론으로 합치지 않고** 각각 따로 보여줍니다.
- **매출 기준은 확인하지 않습니다.** 이 도구는 고시의 *배제기준*만 봅니다. **직전연도 매출(공급대가)이 기준액 이상이면 배제기준과 무관하게 일반과세**입니다. 즉 여기서 "배제기준에 안 걸림"이 나와도 그것만으로 간이과세가 확정되지 않습니다.

그래서 설계 원칙을 이렇게 잡았습니다.

- **판정에는 항상 근거 원문을 함께 표시합니다.** 요약만 보여주고 원문을 숨기지 않습니다.
- **애매하면 판정하지 않습니다.** 적용범위 문구의 의미를 자동 판별할 수 없는 경우(지역기준 647행 중 448행, 69%)에는 코드 대조를 시도하지 않고 원문만 보여줍니다. 추측해서 알려주는 것이 침묵보다 위험하다고 봤습니다.
- **범위로 지정된 업종코드는 확정하지 않습니다.** 범위 안에 들어가도 "들어갑니다, 원문을 확인하십시오"까지만 안내합니다.

## 근거 데이터

- **국세청 고시 제2026-19호** 「간이과세 배제기준」 (2026년 7월 1일 시행)
- 출처: [국세청 고시 게시판](https://www.nts.go.kr/nts/na/ntt/selectNttList.do?mi=2205&bbsId=1120)
- 해당 데이터는 공공데이터포털에 **이용허락범위 제한 없음**으로 등재되어 있습니다.
- 원문 HWPX에서 별표 4종(종목기준·부동산임대업기준·과세유흥장소기준·지역기준)과 조문을 추출해 JSON으로 변환했습니다.

**고시는 연 1~2회 개정됩니다.** 화면 하단에 이 도구가 기준으로 삼은 고시번호와 시행일이 표시되니, 최신 고시와 일치하는지 확인하고 사용하십시오.

## 다루지 않는 것

- **부동산임대업기준**(제3조), **과세유흥장소기준**(제2조) — 판정 기능이 없습니다.
- **주소 자동 매칭** — 고시의 소재지 표기가 비정규(`화곡동 1117(부번포함)1118-(2∼6,11)`)라 자동 매칭을 포기했습니다. 건물명·지명 검색과 세무서 드릴다운으로 접근합니다.
- **전체 업종코드 검색** — 수록된 127건은 *배제업종 목록*이지 전체 업종코드표가 아닙니다. 검색 결과가 없다는 건 "그런 업종이 없다"가 아니라 "배제업종 목록에 없다"는 뜻입니다. 업종코드를 모르시면 [홈택스](https://hometax.go.kr)에서 조회하십시오.

그 밖의 알려진 한계는 개발 저장소의 `doc/simple-vat-check 알려진 한계.md`에 정리해 두었습니다.

## 기술

빌드 도구·서버·외부 라이브러리 없이 **HTML + 바닐라 JS + JSON**으로만 동작합니다. 파일을 내려받아 `index.html`을 브라우저에서 직접 열어도 그대로 작동합니다. 외부로 나가는 네트워크 요청이 없으므로 **입력한 업종코드·면적·월세는 어디에도 전송되지 않습니다.**
